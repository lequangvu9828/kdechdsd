# HDSD BPM · Kinh Đô

Hướng dẫn sử dụng 6 quy trình trên Base BPM (QT-01, QT-02, QT-03, QT-05, QT06, QT07), một trang HTML nhiều tab.

- `index.html`: trang hoàn chỉnh (mở trực tiếp hoặc bật GitHub Pages).
- `src/content.py`: nội dung từng quy trình (bước, người làm, thao tác, tình huống).
- `src/build.py` + `src/template.html`: tạo `index.html`. Chạy `python3 src/build.py`.
- `src/img/`: ảnh chụp màn hình BPM.

Giao diện theo design system "HTML for Base". Dữ liệu đọc từ hệ thống ngày 20/11/2026.
